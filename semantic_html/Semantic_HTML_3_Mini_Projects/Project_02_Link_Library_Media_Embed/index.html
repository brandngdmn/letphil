Link Best Practices

  • Use descriptive link text (not "click here")
  • Use target="_blank" for external links
  • Use rel="noopener" for security on external links
  • Ensure internal links point to existing ids
  • Test links to make sure they work correctly

Descriptive links improve accessibility by providing context to screen readers and users who rely on assistive technologies. They help users understand where the link will take them, making navigation easier and more intuitive.
